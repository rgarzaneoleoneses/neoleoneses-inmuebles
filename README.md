## Ejecutar localmente
Clona o descarga este repositorio. En la raíz ejecuta `python3 -m http.server 8080` (Windows: `py -m http.server 8080`). Abre http://localhost:8080/. Se requiere internet para cargar los mapas.

## Archivos
- `index.html`: aplicación editable, datos simulados, HTML/CSS/JS.
- `municipios-nl.json`: geometrías de 51 municipios de INEGI.
- `photos/`: 28 archivos fotográficos de referencia.
- `vercel.json`: configuración estática.
- `docs/README-original.md`: guía de la copia publicada.

## Colaboración
Invita al socio desde Settings > Collaborators para concederle permisos. Cada socio conecta su cuenta GitHub en ChatGPT y autoriza el repositorio. Consulta AGENTS.md y CONTEXTO.md; trabaja mediante ramas y pull requests. No compartas credenciales. La importación a GitHub no modifica la plataforma de producción ni habilita despliegues automáticos.

Los 500 anuncios, imágenes, contactos y lugares de interés son ilustrativos. No constituyen ofertas reales. Valida los términos de mapas y fotos antes de comercializar.
