# Neoleoneses Inmuebles v0.8.9

Copia estática de la versión pública: https://neoleoneses-inmuebles.vercel.app/

Descomprime el ZIP. Abre una terminal en la carpeta con index.html.
Ejecuta `python3 -m http.server 8080` (Windows: `py -m http.server 8080`).
Visita http://localhost:8080/. Se requiere internet para la cartografía externa.

Archivos: index.html (HTML, CSS, JS), municipios-nl.json (INEGI), photos/ (fotografías ilustrativas), vercel.json (configuración estática).
500 inmuebles ficticios, 51 municipios. No hay propiedades ni contactos comerciales reales; las fotos de Unsplash y los servicios cercanos son ilustrativos. No incluye credenciales, cuentas, pagos ni backend. Revisar licencias de mapas y fotografías antes de uso comercial. Consulta el Markdown independiente para el contexto de ChatGPT.
